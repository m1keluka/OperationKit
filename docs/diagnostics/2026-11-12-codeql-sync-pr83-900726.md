## What actually blocks the merge

- Branch protection on public `main` requires **only** `gate`. There are no repo or org rulesets, so no
  code-scanning merge rule exists. A red `CodeQL` check alone shows as *unstable*, not *blocked*.
- `required_conversation_resolution` is **on**. The CodeQL bot opened one review thread per new alert in
  the diff, and 44 were unresolved. **Those unresolved threads are what make `mergeStateStatus=BLOCKED`.**
- Precedent: #81 merged on 2026-11-11 with its CodeQL check red and 9 threads unresolved, via an
  admin bypass (`enforce_admins=false`).

## Why the suppression comments do not clear the check

The 2026-11-11 decision (obj 900560, private PR #701) added an advanced-setup workflow, a `paths-ignore`
config for test files, and `AlertSuppression.ql` + `dismiss-alerts`. All of it is gated on the repo variable
`CODEQL_ADVANCED_SETUP=true`. The cutover was never done: the public repo has **no Actions variables**, and
**default setup is still `configured`**, which is why the CodeQL Actions workflow shows as skipped. Default
setup ignores both `paths-ignore` and `codeql[...]` comments. That explains why test-harness CSRF alerts and
every in-house-limited route keep resurfacing on each rolling sync.

## Smallest safe way to merge rolling syncs

1. **Now (per PR):** triage the bot threads on the sync PR as done here. Resolve each thread with a one-line
   reason (baseline, test harness, or fixed in private PR N). Alerts stay **open** in code scanning; nothing
   is dismissed. Resolving the threads lifts the conversation-resolution block, so a maintainer can merge
   without an admin bypass.
2. **Structural (separate, owner-gated change):** finish the advanced-setup cutover in the public repo
   settings. Disable default setup and set `CODEQL_ADVANCED_SETUP=true` in the same step. Then test
   harnesses are out of scope and justified suppressions dismiss on `main`. Expect one noisy PR after the
   switch, because the first advanced analysis has no `main` baseline in its category.
3. Do **not** make `CodeQL` a required check while 466 alerts are open on `main`. Do **not** turn off
   conversation resolution, and do not bulk-dismiss alerts.
