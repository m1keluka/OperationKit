OperationKit documentation

Self-hosted AI operations board. This is the index for the Markdown docs that ship in the repository — the source of truth, versioned with the code.

Quickstart

git clone https://github.com/m1keluka/OperationKit.git
cd OperationKit
cp .env.example .env   # fill in the core values
docker compose up -d

Full walkthrough, including first login and seeding users, is in SETUP.md. For a one-command droplet install, see DIGITALOCEAN.md.
